# Expense Tracker

A simple full-stack expense tracker where users can sign up, log in, and manage their income and expenses.

---

## ✅ What this app does

- User **Signup / Login**
- **JWT Authentication** (keeps data private)
- Add **Income / Expense** transactions
- View transactions on dashboard
- Auto logout on unauthorized access

---

## 🧰 Tech Stack

**Frontend:** React, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Auth:** JWT
